How to Use in Revenge

  1. Host index.html, manifest.json, and OrbSuiteSpoofer.js on HTTPS (such as GitHub Pages).
  2. Open Revenge → Settings → Plugins → +, paste the folder URL, and make sure the plugin toggle is ON.
  3. Tap the plugin's settings/wrench icon to open the shop, Nitro suite, badges, and 100 device presets.
